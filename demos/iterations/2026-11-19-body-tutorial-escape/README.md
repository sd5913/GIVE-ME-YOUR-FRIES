# 第二步：全身体感动作教学

## 抓完后逃跑灵敏度补修（以此处为准）

抓取成功立即准备逃跑，不再要求额外收臂。抓后保护由 260ms 缩至 80ms，双侧手肘展开确认由 180ms 缩至 100ms，展臂阈值适度放宽。明确双臂展开优先于残留的张掌/握拳候选：取消未完成的下一次抓取后逃跑，不额外加薯条。单臂伸手、短暂抖动及没有薯条仍不能逃跑。教学文案同步更新。

补修后 27/27 项模拟检查通过，包含抓 1/2/3 根直接展开、张掌重开不锁死、单臂拒绝和短噪声拒绝。原脚本备份在 qa/flight-before-escape-fix.js。真实摄像头反应速度仍待试玩。

入口 index.html；完整包包含 flight.css、flight.js、scene.js。继承 step1-body 的起飞、收翅、抓取隔离修复。原版本保留，本轮未上传 GitHub。

## 玩法变化

Chrome 开启相机并校准后，点击“开始体感”先进入动作练习。五步为拍翅两次、侧倾对准、收翅、同手张开握拳、收臂后重新展开逃跑。面板显示当前一步、动态图符及说明，现有爪子、翅膀和飞行画面提供操作反馈。识别失败可以继续尝试，也可重练或跳过。完成后倒数三秒，开始全新一趟正式游戏。

教学复用现有游戏状态和动作判断；练习抓取不触发游客攻击，完成展翅后暂停回巢计时和移动，倒数结束清除练习得分、薯条及手势状态。键盘仍可直接试玩。返回设置后再次开始体感可以重新练习。

## 真人验收

1. 用内置相机和 DJI 各完成一次校准与五步练习，检查失败时是否仍可继续尝试。
2. 邀请三名未玩过的新手，不给口头提示，记录每步耗时、是否求助，以及“看不懂/做不到/未识别”的失败原因。
3. 建议至少两人能独立走完教学和正式回巢；不达标先修失败步骤。
4. 测试抓取途中遮手、肘出镜再恢复；不能自动跳步或给分。
5. 各步检查重练、跳过、设置返回；真实全屏检查面板、提示、两翼及爪子是否遮挡。

后续依计划进入节奏和速度感对比前，先完成真人核心动作验收。
