# GIVE ME YOUR FRIES! 大屏身体交互计划

## 1. 第一版要验证什么

把《GIVE ME YOUR FRIES!》做成可以站在大屏前玩的单人副本。玩家用身体带动金帽海鸥，完成一次「飞到薯条盒 → 抓薯条 → 躲开游客红圈 → 回巢计分」的循环。

第一版使用阳光长码头，一局 60 秒。它有摄像头取景、站姿校准、计时、得分和再玩一局。体感 Demo 在仓库中有独立入口，v2.3 手势版仍可直接打开。

[单人全身体感 Demo 源码](../demos/full-body/index.html) · [v2.3 手势版](../GIVE_ME_YOUR_FRIES_DUO_GESTURE.html)

## 3. 动作与反馈

| 玩家做什么 | 海鸥怎么动 | 屏幕反馈 |
| --- | --- | --- |
| 在取景框中央站直约 1 秒 | 记录站姿高度和身体中线 | 绿色骨架、校准进度条 |
| 小步侧移或轻移重心 | 向同侧飞，回到校准中线就停下横向移动 | 左右方向与镜像预览一致 |
| 双臂像翅膀一样抬过肩或放低 | 抬高上升，放低下降，平举保持高度 | 海鸥在地图内连续移动 |
| 到薯条盒附近保持半蹲 | 俯冲并抓薯条，一次最多四根 | 薯条画在脚上，计分栏显示携带数量 |
| 抓到第一根薯条 | 游客开始警戒，红圈倒计时 1.65 秒 | 红圈、提示音和剩余时间 |
| 带着薯条站直 | 自动飞向巢穴，送到后每根计 1 分 | 回巢提示和得分动画 |
| 在倒计时结束时仍留在红圈里 | 游客击晕海鸥，掉落脚上的薯条 | 已经入巢的分数保留 |
| 头、手或脚出画，或视频停止更新 | 暂停移动、抓取和计时，重新入镜后恢复 | 屏幕提示回到取景范围 |

全程用站姿、低幅侧移和半蹲。大屏边保留全屏、返回设置和键盘试玩按钮，方便布置和排查。键盘用 WASD 或方向键飞行，按住 F 抓取，松开 F 回巢。

## 4. Pocket 4P 和大屏接线

1. 把 Osmo Pocket 4P 接上带数据传输能力的 USB-C 线，另一端接电脑。在相机的 USB 菜单选择 **Webcam**。电脑另接大屏。 [DJI FAQ](https://www.dji.com/uk/osmo-pocket-4p/faq) · [DJI 用户手册](https://assets.ctfassets.net/et769tc4wc1v/3DUyNXRpjyzO1CsrLTLI5O/fb4427be2aae9bfffb73a8bf5bb34080/DJI_Osmo_Pocket_4P_User_Manual_en.pdf)
2. 把相机固定在屏幕附近，镜头正对活动区。用镜像预览确认传到电脑的是广角画面。可以从离镜头约 2 米试起，根据取景前后调整，让双臂伸展和半蹲时的头、手、脚都完整入画。
3. 下载本仓库，在仓库根目录执行 `python3 -m http.server 8000 --bind 127.0.0.1`，用 Chrome 打开 [本地 Demo](http://127.0.0.1:8000/demos/full-body/)。开启摄像头并允许权限，再在「视频输入」中选择 DJI。首次加载姿态模型需要联网。
4. 等模型加载完成，点击「校准站姿」。站在活动区中央、双腿站直并保持约 1 秒。校准完点击「开始体感」，再切到全屏。换机位、相机输入或玩家后重新校准。

页面通过浏览器读取视频，画面在本机做姿态识别。摄像头列表里也可选电脑内置摄像头或系统识别的采集设备。广角镜头、USB 输出范围和现场光照以预览和实机测试为准。

## 5. 大屏试玩验收

| 要核对的项目 | 通过条件 |
| --- | --- |
| Pocket 4P 输入 | Chrome 设备列表能选到 DJI，画面方向正确，广角取景能容下站姿、伸臂和半蹲。 |
| 新玩家能开局 | 能根据骨架和取景提示完成校准，开始时能分辨左右和升降。 |
| 动作是否可靠 | 分别试左右移动、双臂升降、半蹲、起身各 5 次，记录触发、误触发和失败次数。站直或只放低双臂时遇到薯条盒，检查是否误抓。 |
| 完整玩法 | 用体感完成抓取、躲过一次红圈并回巢计分。再留在红圈内一次，确认只掉落携带的薯条。 |
| 遮挡与断线 | 短暂离开取景，海鸥停住，计时暂停。回来后能继续。拔下相机时可返回设置并重新选择输入。 |
| 大屏可读性 | 从玩家站位能看清剩余时间、携带量、得分和红圈倒计时。现场记录不同机位、光照和相机输出下的表现。 |
