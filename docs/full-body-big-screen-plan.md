### 从起飞到回巢的操作

| 阶段 | 身体互动 | 键盘试玩 |
| --- | --- | --- |
| 起飞 | 张开双臂，上下拍两次 | 空格或 W 按两次 |
| 对准薯条 | 上半身缓慢侧倾控制左右 | A / D，或左右方向键 |
| 俯冲 | 靠近并对准后，将两侧手肘收向身体 | 对准后自动俯冲，不需要 S |
| 抓取 | 一只手伸到胸前张开五指，再用同一只手握拳；每次完整动作抓一根 | 每按一次 E 自动完成一次张爪和闭爪，抓一根；不需要再按 F |
| 向上逃跑 | 抓到薯条后双臂展开，海鸥升空离开游客 | 空格或 W，直接向上飞走 |
| 飞越货箱 | 再次拍翅，短暂拉升高度 | 空格或 W |
| 绕过招牌 | 侧倾转向空的一侧 | A / D |
| 入巢 | 沿栈道飞到尽头，最后一段自动对准并入巢 | 同左 |

### 游客生气与躲避节奏

拿着薯条的原蓝色游客会随着偷取和警戒进度逐渐变红，并出现生气表情。不会从海边额外弹出红色游客。抓到第二根触发警戒，约 **2.8 秒**后发动攻击；玩家可以贪第三根，也可以立即展开翅膀向上飞走。离开后给出逃脱反馈。

被游客击中会掉光当趟携带的薯条，已经存进巢穴的分数保留。取消 Shift 加方向键与快速侧倾闪避，统一使用拍翅／展翅向上逃跑。

### 回巢跑酷

栈道由原来的场景终点 1985 延长至 3500，回巢倒计时为 **20 秒**。当前安排三处障碍：货箱、单侧高招牌、货箱。货箱需要拍翅拉升，招牌需要左右绕开；障碍接近时显示大字动作提示。拍翅同时提供短时加速。

擦碰障碍掉一根随身薯条并短暂减速，同一个障碍不会连续扣除；没有薯条时仍可完成回巢。入巢后只累计实际带回的数量。

## 3. 动作与反馈

| 玩家做什么 | 海鸥怎么动 | 屏幕反馈 |
| --- | --- | --- |
| 在取景框中央站直，双手放在腰前约 1 秒 | 记录身体中线、站姿和双手的基准高度 | 绿色骨架、校准进度条 |
| 小步侧移并停住 | 移到同侧对应的位置，站稳后停住 | 左右方向与镜像画面一致 |
| 双手从腰前抬高或放低 | 直接改变海鸥的高度，双手回到腰前时对应画面中部 | 海鸥平滑跟随手臂变化 |
| 到薯条盒附近保持半蹲 | 抓薯条，一次最多四根 | 够得着的薯条盒亮起黄圈，抓到的薯条画在脚上 |
| 抓到第一根薯条 | 游客开始警戒，红圈倒计时 1.65 秒 | 红圈、提示音和剩余时间 |
| 带着薯条站直 | 自动飞向巢穴，送到后每根计 1 分 | 回巢提示和得分动画 |
| 在倒计时结束时仍留在红圈里 | 游客击晕海鸥，掉落脚上的薯条 | 已经入巢的分数保留 |
| 头、手或脚持续出画，或视频停止更新 | 暂停移动、抓取和计时，重新入镜后恢复 | 屏幕提示回到取景范围 |

全程用站姿、低幅侧移和半蹲。大屏边保留全屏、返回设置和键盘试玩按钮，方便布置和排查。键盘用 WASD 或方向键飞行，按住 F 抓取，松开 F 回巢。

## 4. Pocket 4P 和大屏接线

1. 把 Osmo Pocket 4P 接上带数据传输能力的 USB-C 线，另一端接电脑。在相机的 USB 菜单选择 **Webcam**。电脑另接大屏。 [DJI FAQ](https://www.dji.com/uk/osmo-pocket-4p/faq) · [DJI 用户手册](https://assets.ctfassets.net/et769tc4wc1v/3DUyNXRpjyzO1CsrLTLI5O/fb4427be2aae9bfffb73a8bf5bb34080/DJI_Osmo_Pocket_4P_User_Manual_en.pdf)
2. 把相机固定在屏幕附近，镜头正对活动区。用镜像预览确认传到电脑的是广角画面。可以从离镜头约 2 米试起，根据取景前后调整，让双臂伸展和半蹲时的头、手、脚都完整入画。
3. 下载本仓库，在仓库根目录执行 `python3 -m http.server 8000 --bind 127.0.0.1`，用 Chrome 打开 [本地 Demo](http://127.0.0.1:8000/demos/full-body/)。开启摄像头并允许权限，再在「视频输入」中选择 DJI。首次加载姿态模型需要联网。
4. 等模型加载完成，点击「校准站姿」。站在活动区中央，双手放在腰前，双腿站直并保持约 1 秒。校准完点击「开始体感」，再切到全屏。换机位、相机输入或玩家后重新校准。

页面通过浏览器读取视频，画面在本机做姿态识别。摄像头列表里也可选电脑内置摄像头或系统识别的采集设备。广角镜头、USB 输出范围和现场光照以预览和实机测试为准。

## 5. 大屏试玩验收

| 要核对的项目 | 通过条件 |
| --- | --- |
| Pocket 4P 输入 | Chrome 设备列表能选到 DJI，画面方向正确，广角取景能容下站姿、伸臂和半蹲。 |
| 新玩家能开局 | 能根据骨架和取景提示完成校准，开始时能分辨左右和升降。 |
| 动作是否可靠 | 分别试左右移动、双臂升降、半蹲、起身各 5 次，记录触发、误触发和失败次数。站直或只放低双臂时遇到薯条盒，检查是否误抓。 |
| 完整玩法 | 用体感完成抓取、躲过一次红圈并回巢计分。再留在红圈内一次，确认只掉落携带的薯条。 |
| 遮挡与断线 | 短暂离开取景，海鸥停住，计时暂停。回来后能继续。拔下相机时可返回设置并重新选择输入。 |
| 大屏可读性 | 从玩家站位能看清剩余时间、携带量、得分和红圈倒计时。现场记录不同机位、光照和相机输出下的表现。 |

## 6. 下一轮试玩

1. **把教学做成三次试动作。** 开始计时前，依次让玩家侧移、抬手、半蹲。每完成一次就点亮对应图标，并标出没识别到的部位，让玩家能在试玩前调整站位。
2. **试一轮 20 秒的伸手抢薯条。** 从 Reaction 借鉴短回合与直接碰目标的玩法。先在左右手舒适可达的位置出现一盒薯条，碰到就给分；单动作稳定后，再试侧移躲游客红圈。
3. **用动作和声音说明为什么得分。** 碰到薯条给短音效和飞入巢穴的动画，红圈被躲过时给一次清晰反馈。用 DJI 试玩时，分别记录漏判、误触和动作还要做多大的问题。
